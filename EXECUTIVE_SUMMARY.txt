================================================================================
                              API ENDPOINTS
================================================================================

NOTIFICATIONS:
✅ GET    /api/notifications              (get all with filtering)
✅ PATCH  /api/notifications/{id}/read    (mark as read)

COOKING SESSIONS:
✅ GET    /api/recipes/{id}/cook/readiness     (check availability)
✅ POST   /api/recipes/{id}/cook                (start cooking)
✅ POST   /api/cooking-sessions/{id}/cancel    (cancel & rollback)
✅ POST   /api/cooking-sessions/{id}/complete  (finish cooking)
✅ GET    /api/cooking-sessions/active         (get active session)

All endpoints require JWT authentication (Bearer token).

                        HOW TO RUN & TEST
================================================================================

QUICK START:
1. cd backend && ./gradlew run        (start backend on port 8081)
2. adb reverse tcp:8081 tcp:8081     (setup device connection)
3. cd app && ./gradlew installDebug  (install APK)
4. Open app → Register/Login
5. Add pantry items with expiry dates
6. Check notification screen (bell icon)
7. Find recipe → Start cooking → Cancel/Complete
